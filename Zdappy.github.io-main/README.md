## Тематика сайта, название
**Интернет-магазин «Новая Эра»**  
Тематика: продажа цветов, рассады, семян и посадочного материала.

## Цель и задачи системы
### Цель
Создание работоспособного веб-приложения для онлайн-продажи товаров для сада и огорода, обеспечивающего удобный поиск, выбор и оформление заказов.

### Задачи
- Реализовать каталог товаров с возможностью фильтрации по категориям и цене.
- Разработать функционал корзины: добавление, изменение количества, удаление товаров и автоматический расчёт суммы.
- Обеспечить пользовательскую аутентификацию (регистрация, вход, выход) с безопасным хранением паролей.
- Настроить взаимодействие с базой данных через ORM для хранения информации о пользователях, товарах и заказах.
- Реализовать REST API для асинхронного взаимодействия фронтенда с сервером.
- Создать адаптивный пользовательский интерфейс, корректно отображающийся на мобильных устройствах и десктопах.

## Целевая аудитория
- **Садоводы-любители и дачники (30–65 лет)** — ценят простоту интерфейса, крупные элементы управления, отсутствие навязчивой анимации.
- **Начинающие огородники** — нуждаются в подробных описаниях товаров, фотографиях и подсказках по уходу.

*Отличие от обобщённого пользователя:* аудитория имеет конкретную сезонную потребность и часто просматривает сайт в полевых/дачных условиях. Дизайн ориентирован на быструю навигацию, контрастные цвета для чтения при ярком освещении и оптимизированную загрузку изображений.

## Содержание сайта
1. **Главная страница** — приветственный баннер, категории товаров, популярные позиции.
2. **Каталог товаров** — список/сетка товаров с фильтрами, поиском и сортировкой.
3. **Страница товара** — детальная информация: фото, описание, цена, наличие, кнопка добавления в корзину.
4. **Корзина** — выбранные позиции, управление количеством, расчёт итоговой суммы.
5. **Страницы аутентификации** — формы входа и регистрации (фронтенд + серверная обработка).
6. **Личный кабинет** — история заказов, данные профиля.
7. **Кастомные страницы ошибок** — шаблоны 404, 403, 500.

## Функциональные возможности
* Просмотр каталога с фильтрацией по категории, цене и наличию
* Детальный просмотр карточки товара с описанием и характеристиками
* Добавление/удаление товаров в корзину без перезагрузки страницы (AJAX)
* Автоматический пересчёт итоговой стоимости заказа
* Регистрация и авторизация пользователей с валидацией форм и CSRF-защитой
* Хранение паролей в хешированном виде (Werkzeug / Flask-Bcrypt)
* Защита личных маршрутов декоратором `@login_required`
* REST API endpoints для получения списка товаров и управления корзиной (JSON)
* Адаптивная вёрстка (Bootstrap / кастомный CSS) для мобильных и десктопных устройств
* Наследование шаблонов: единый `base.html` с вынесенными header, footer и навигацией
